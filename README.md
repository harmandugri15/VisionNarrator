# VisionNarrator
VisionNarrator is an AI image captioning system that combines a Vision Transformer (ViT) with a pretrained language model. Using transfer learning and the COCO dataset, it extracts visual features and generates natural-language descriptions of what is happening in an image.

# Note
Strictly do not work by loding or downloading the data locally . Performing such tasks should be done by calling API methods because by this , everyone can follow the same path . 

Use a virtual environment with python version >= 3.11.9 . (Recommended)


# Understanding Directory Structure . 
/notebooks directory is Used to Store all the Seperate or Individual notebooks for the complete Project .

/docs directory will store all the necessary information required to refer to the notebooks in future . it will contain the necessary documentations for the model reference . 

/src directory will contain all the work related to storing data , storing all the necessary packages and information for data or anything which cant be pushed to github .
